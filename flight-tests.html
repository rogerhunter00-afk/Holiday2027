What we should compare

  • Does it find the same airlines and routes?
  • Are the displayed prices credible and correctly tied to dates?
  • Can it handle flexible requests such as “any Scottish airport” and “about a week”?
  • How fast is each method on mobile?
  • Does either method miss low-cost carriers or show stale/partial results?

The structured API route is the production candidate. The browser + Gemini route is deliberately separate so we can keep it as an independent fallback rather than mixing both methods during testing.
