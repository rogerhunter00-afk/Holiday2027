Airbnb URL parser test

This page compares the two automatic routes on the same Airbnb URL. Test 1 asks Airbnb directly for its HTML. Test 2 opens the page in a real remote browser, takes a screenshot, then lets Gemini 3.1 Flash-Lite read what actually rendered.

Rendered-browser tests use Microlink's free browser endpoint, currently limited to 25 requests/day on its free plan.

1. Direct page extraction

FAST · no browser

Fetches the canonical Airbnb room page server-side and searches the returned HTML for listing titles and property images.

2. Rendered browser + Gemini

REAL BROWSER · GEMINI VISION

Renders the Airbnb page in a remote browser, captures what a browser actually sees, then sends that screenshot to Gemini for extraction.
